## Attack Description
Most attacks begin with reconnaissance, where an attacker gathers information about a target to plan their next steps. One way to gather information about a target device or network is through port scanning. A port scan can reveal open ports, running services, and active hosts, providing insight into the target's network configuration and potential attack surfaces. Port scanning generally does not require prior access to the target; it only requires network connectivity between the attacker and the target.
